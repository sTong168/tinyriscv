### 8.2 统一 `tinyriscv_soc_top` 端口（组长示意图）

流片面向的 CPU/SoC 顶层 **不再暴露** GPIO、JTAG、`ext_rom_*` 等 FPGA 用口，改为：

```verilog
module tinyriscv_soc_top (
    input  wire       clk,
    input  wire       rst,
    output wire       over,          // 测试结束
    output wire       succ,          // 测试成功
    input  wire       uart_debug_pin,
    output wire       uart_tx_pin,
    input  wire       uart_rx_pin,
    input  wire [7:0] bridge_i,      // 外存桥 8 位入（含带内 ACK）
    output wire [7:0] bridge_o,      // 外存桥 8 位出（含 HDR 握手）
    output wire [3:0] pwm,
    input  wire       scl_in,
    output wire       scl_o,
    output wire       scl_oe,
    input  wire       sda_in,
    output wire       sda_o,
    output wire       sda_oe
);
```

**含义简述：**

| 信号组 | 为何这样接 |
|--------|------------|
| `bridge_i` / `bridge_o` | 片外 ROM/RAM 走 8 位桥；与 `em_dat` 双向相比，便于 PAD 用两根单向总线 + 片外三态 |
| `scl_*` / `sda_*` 各 3 根 | 工艺 PAD 是三态门；I2C 开漏要在顶层用 `oe` 控制，不能只用 `inout` 一根线 |
| `pwm[3:0]` | 课程 4 路 PWM，与组长 `pwm.v` 一致 |
| 无 GPIO/JTAG | 与《后端流程.pdf》§1.1 ③ 一致 |

组长在外层再做：`chip_sel` 选四核之一 + PAD 与 `io.file` 对齐。**你改的是「单核 + 统一端口」这一层。**

### 8.3 你还需自己做的（资源修改 1.1）

组长三件套 **不替代** PDF 里的 CPU 删减，你仍要：

1. 删 **M 扩展**（mul/div/rem）及 `div.v`
2. 删 **CSR / CLINT / 异常** 及 `clint.v`、`csr_reg.v`
